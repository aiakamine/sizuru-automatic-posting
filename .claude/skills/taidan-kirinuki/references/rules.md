# 4つの絶対ルールと、その担保のしかた

守れているかを「目で見て確認」で済ませない。全部、機械で検査できる形に落とす。

## 1. カットの繋ぎによるテロップの表示ずれをなくす

元データの焼き込みテロップをそのまま使うので、カット点がテロップの切り替わりと
1フレームでもずれると「前のテロップが残る」「次のテロップが先に出る」が起きる。

- **座標系は telops.txt だけ**。VTT自動字幕はタイミングが不正確なので文脈把握にしか使わない
- カット頭 ＝ 新しいテロップが出た最初のフレーム（`bounds.json` の切替完了フレーム）
- カット尻 ＝ 次のテロップに変わり始める1つ前のフレーム（`gstart`。render.py が自動で下げる）
- 検査：`qc.py` が各カットの1・2フレーム目と最終2フレーム目をOCRして期待テロップと突き合わせる。
  OCRの認識ゆれ（「Q2.CSV」と「Q2.csv」等）以外の不一致が出たら作り直し

**A/Vのズレも同じ扱い**。カットを個別mp4にして concat デムクサで繋ぐと、セグメントごとに
映像と音声の長さが最大33msずれ、繋ぐたびに累積する。必ず trim/atrim＋concat **フィルタ**で
1コマンドに通す（render.py はそうしている）。書き出し後に映像と音声の duration の差が
1フレーム以内であることを確認する。

## 2. 冒頭のフックを意識したシーン選定

C1は「いちばん強い一言、またはいちばん強い画」から入る。次のものは引きが弱いので使わない。

- 結果画面の実況（「出ました、こんな感じです」「スライドができていますね」）
- 文脈前提の出だし（「2つ目が」「次4つ目ですが」「では続いて3つ目ですね」）
- 静止画（ゲームのタイトル画面など）。**フレーム間差分を測って動いているか確認する**
- 主張だけで画が無いカット（対談カットの上に結論を乗せただけ）

強いのは、①数字・断定（「人間だったら5分間で出来ない／無理ですね」）②成果物そのもの
（「【初心者向け】そのまま使えるレシピ7選」の画面）③視聴者の疑問の代弁
（「Claude Codeでしかできないことは?」「いちいち連携しないと使えないのでは」）。

画と言葉は両方見る。**同じ画面のままベネフィットを言っている箇所**があればそれが最良
（例：空き日程の表を出しながら「自分でカレンダーを見に行って空き時間を調べなくても、すぐ出してくれる」）。

## 3. ハイライト→本編はトランジションを使用する

C1→C2は白フラッシュ0.35秒（`xfade=transition=fadewhite` ＋ `acrossfade`）。C2以降は素のカット。

例外：元データの章アイキャッチ（脳のアニメーション等）をフック直後に置く回は、
アイキャッチが繋ぎを兼ねるので `"xfade": 0.0` にしてフラッシュを外す。
その場合、**アイキャッチは頭から出し切る**（フラッシュを被せて白飛びさせない）。

## 4. 文脈がつながらないシーン繋ぎ・終わり方はしない

**テロップの区切り＝文の区切りではない。** テロップが終わっても発話は次のテロップまで
続いていることが多く、そこで切ると語尾が欠ける。逆に無テロップ区間まで伸ばすと
次の話題の頭（「そしたら最後に」「またはですね」）が残る。

**カット点は「安全なカット点の一覧」からしか選ばない。** 手順：

```bash
python3 scripts/cutpoints.py <src.mp4> <workdir>          # → 語尾分類・無音判定の候補表
python3 scripts/safe.py  <src.mp4>                 # → safe.txt（テロップ境界×無音の一覧）
python3 scripts/pick.py  <src.mp4> <開始秒> <終了秒>  # → その区間で切っていい点を表示
python3 scripts/chop.py  <src.mp4> <workdir> <clips.py>   # → ぶつ切りが0件になるまで直す
python3 scripts/align_check.py <src.mp4> <workdir> <clips.py>  # → 発話とテロップの一致検査。NG 0件になるまで直す
```

- `cutpoints.py` は telops.txt の各行について語尾分類（言い切り／引用止め／継続形）・
  終点付近の無音判定（絶対レベル。`chop.py` と同じ規約）・（`--whisper` を付けた場合のみ）
  次の発話までの間を機械的に一覧にする。**最終判断は人が本文を読んで行う**が、
  候補を絞る一次スクリーニングとして使う
- `align_check.py` は `chop.py`（音量）とは別に、**Whisperで実際の発話とテロップ本文を
  突き合わせる**。テロップが語を補っている（例：テロップは「結果が出てるのに評価されてない人とかも」だが
  実際の発話は「出てるのに」から）ためカット頭が発話の途中から始まる事故や、カット尻が
  語の途中で切れる事故を検出する。`chop.py` が0件でも `align_check.py` がNGを出すことがあるので
  両方を通す

- `safe.py` は全編の音声を1回読み、10秒ブロックの中央値を基準に無音を検出して、
  テロップ境界のうち無音に載っているものだけを SAFE として出す
- `pick.py` は加えて**無テロップ区間**（作業画面・BGMだけの区間）の無音も候補に出す。
  テロップが出ていない区間はどこで切ってもテロップずれが起きないので自由に切れる
- `chop.py` が最終判定。カット点の直前60ms／直後60msの実効レベルを見て、
  **両側とも-26dBFSを超えていたら「ぶつ切り」**。BGMは-30dB前後なので誤検知しにくい。
  0件になるまで直す
- `pauses.py`（局所中央値方式）は参考程度に。BGMが発話に近い音量の場面で過検知する

そのうえで、最後のテロップの語尾が言い切り（す／た／ね／か／？）か継続（て／で／が／ので／
など）かを本文で読んで人が決める。

繋ぎで詰まったら：
- 頭が「〜て」「〜とか」で始まるカットは、1つ前のテロップまで戻して文の頭から始める
- 話が飛ぶ箇所には、無テロップ区間（打ち込み画面・結果画面）をブリッジのカットとして挟む
- 質問が出たら答えまで入れる。答えの無い質問で終わらない
- 最後のカットは段落の言い切りで終える。終わりのフェードが語尾に掛かるなら
  `"outfade": 0.20` に縮めて無音の中でフェードさせる
