## デザインが変わっていないかの確認

シーズンや担当編集者が変わるとバナー形状・位置が変わる。**制作前に必ず**チャンネルの
最新の公開済みショートを1本落として実測する。

```bash
yt-dlp --cookies-from-browser chrome -f "bv*+ba/b" --merge-output-format mp4 -o ref.mp4 <公開済みショートURL>
python3 scripts/measure_layout.py ref.mp4
python3 scripts/extract_cta.py ref.mp4 cta.mp4
```

実測値が上の表と違ったら、`clips.py` の LAYOUT と `scripts/banner.py` の定数
（BODY_W_TOP / BODY_H / SLANT / LEFT / RAD / C_L / C_R）を合わせてから作る。

## 横を切ってはいけない理由

元データの焼き込みテロップは最長で x=113〜1793 まで使う
（例：製品名を3つ並べたテロップ）。横に寄せると端の文字が切れるので、
既定クロップは横1920のまま。映像バンドを大きくしたい誘惑に負けないこと。
寄せていいのは、そのカットにテロップが無い区間（作業画面など）だけ。
